# 溜小3规则人话版

## 1. 游戏目标

4名玩家通过出牌和质疑，尽量打出自己手里的数字3，同时阻止其他玩家溜3。

最终按以下顺序排名：

1.  **有效霉运越少，排名越高**；
    
2.  有效霉运相同，**最终福运越多，排名越高**；
    
3.  前两项相同，**成功溜走的3越多，排名越高**；
    
4.  三项相同则并列。
    

## 2. 基础配置

*   玩家人数：4人；
    
*   牌库：48张；
    
*   数字2～7各8张，同数字的牌没有区别；
    
*   每局进行3轮，第三轮公示结束后进入气运抽取，随后进行最终结算。
    

## 3. 等待大厅

### 3.1 开始条件

*   玩家进入房间后可点击“准备”，再次点击可取消准备；
    
*   只有房主可以开始游戏；
    
*   4名玩家全部准备后，“开始游戏”按钮才可点击；
    
*   有玩家取消准备或离开时，“开始游戏”立即恢复不可用状态。
    

### 3.2 房主参数

| 参数 | 范围 | 默认值 |
| --- | --- | --- |
| 出牌时间上限 | 5～120秒 | 20秒 |
| 质疑时间上限 | 5～120秒 | 20秒 |
| 单个被质疑者公示时间 | 5～20秒 | 10秒 |
| 气运上限 | 6～15 | 8 |
| 初始霉运数量 | 4～气运上限-1 | 4 |
| 气运抽取次数下限 | 1～抽取上限 | 2 |
| 气运抽取次数上限 | 抽取下限～气运上限 | 5 |

参数变化实时同步给房间内所有玩家。非房主只可查看，不可修改。

### 3.3 大厅UX

*   玩家卡展示头像、昵称、房主标记和准备状态；
    
*   空位显示“等待玩家加入”；
    
*   当前玩家标记“你”；
    
*   房间号旁提供复制按钮；
    
*   “准备”和“开始游戏”分开显示，避免普通玩家误以为可以开局；
    
*   参数不合法时，直接在对应项旁提示原因，并禁止开始游戏。
    

### 3.4 按钮与聊天入口

等待大厅以本节规则和本节下方最新大厅图为准：

*   **右上角**只保留“离开房间”和“菜单”；
    
*   **左下角**固定显示“快捷文字”和“文字输入”；
    
*   其他位置不再显示对话、表情、声音或设置的独立按钮。
    

按钮功能：

1.  **离开房间**：点击后弹出二次确认，确认后离开当前房间；
    
2.  **菜单**：打开规则说明和声音设置；
    
3.  **快捷文字**：从左下角向上展开预设语句，选择后直接发送；
    
4.  **文字输入**：从左下角展开输入框和发送按钮。
    

快捷文字和文字输入不能同时展开。点击空白处或再次点击原按钮关闭面板。

> **配图判定规则：本节下方最新大厅大图是大厅按钮位置的正确版本。旧图如果仍显示右上角“对话、表情、声音、设置”，均不采用。**

## 4. 开局

### 4.1 初始化

*   每名玩家获得6张牌，其中必定包含2张数字3；
    
*   手牌按数字从小到大自动整理；
    
*   根据房主参数生成每名玩家相同的初始气运池。
    

### 4.2 开局表现

*   先播放简短洗牌和发牌动画；
    
*   自己能看到完整手牌，其他玩家只显示手牌数量；
    
*   发牌结束后停留2秒，进入第1轮摸牌阶段；
    
*   动画期间不能进行牌局操作；左下角的快捷文字、文字输入和右上角菜单仍可使用。
    

## 5. 每轮流程

每轮依次进行：**摸牌 → 出牌 → 质疑 → 公示**。

顶部中央始终显示当前轮次、当前阶段和剩余时间。对局内右上角只保留**菜单**；**快捷文字、文字输入**固定在左下角。

### 5.1 摸牌阶段

*   每轮开始时，每名玩家从牌库获得2张牌；
    
*   新牌飞入自己的手牌区后自动排序；
    
*   其他玩家只更新手牌数量，不展示牌面；
    
*   整理完成后停留2秒，自动进入出牌阶段。
    

### 5.2 出牌阶段

#### 选牌规则

满足以下任一条件即可出牌：

*   所选牌全部为同一个数字；
    
*   所选牌中包含数字3。
    

每次至少选择1张牌，并且必须指定其中**恰好1张为明牌**，其余为暗牌。

系统根据“总出牌数＋明牌数字”自动生成声明。例如明牌是5、共出3张，声明为“3张5”。声明不可手动修改。

#### 操作流程

1.  点击底部手牌进行选牌，再次点击取消；
    
2.  选中的牌上移并同步进入现有“出牌预览区”，预览区先正面展示全部所选牌；
    
3.  在预览区点击其中1张牌，将其设为明牌；明牌保留正面并显示“明牌”标记，其余牌翻为背面；
    
4.  点击另一张预览牌可直接更换明牌，旧明牌自动变为暗牌；
    
5.  系统按“总出牌数＋明牌数字”实时生成声明；
    
6.  未指定明牌前，“确认出牌”置灰；若只选1张牌，系统自动将其设为明牌；
    
7.  点击“确认出牌”后，预览区中的牌进入自己的出牌区；
    
8.  阶段结束前可点击“取消出牌”，牌回到手牌区并可重新选择。
    
9.  若未选择明牌：默认排序的第一张为明牌。
    

> 配图统一说明：选牌、指定明牌、确认出牌始终复用同一个出牌预览区，不新增弹窗或第二个预览框。配图中若出现数字8，仅为AI示意错误，实际牌面只有2～7。

#### 信息可见范围

*   自己确认后，可以看到自己的1张明牌、其余暗牌和系统声明；
    
*   出牌阶段中，其他玩家只显示“选择中”或“已出牌”，不展示其牌和声明；
    
*   所有人完成出牌，或倒计时结束时，进入质疑阶段；
    
*   超时未出牌时，系统自动打出当前排序第一张牌，并将该牌设为明牌。

### 5.3 质疑阶段

#### 阶段开始

*   进入阶段后，展示4名玩家本轮的明牌、暗牌数量和声明；
    
*   暗牌保持背面，不展示具体数字；
    
*   信息栏先展示本轮公开情报，再开放质疑操作；
    
*   信息栏只提供数量信息，不指出数字3属于哪名玩家。信息栏样式以![image](https://alidocs.dingtalk.com/core/api/resources/img/5eecdaf48460cde57ac061d5b72bc1d643a725334be18b7c75b8339e1c4c24834ad4804002a0e3d739e8703ac5556d0d868adf8a805e0cd559667673c4c4ad55988d567aba49d675df477d996a76f9358c8d3352130269dc6fcdb4de966884f7)为准。无历史信息时不显示下面的。
    

#### 三轮信息栏

*   第1轮：显示“当前场上有A个对子，其中包含B张3”；
    
*   第2轮：除本轮信息外，增加“第一轮成功溜走C张3”；
    
*   第3轮：除本轮信息外，增加第一轮和第二轮各自成功溜走的3数量；
    
*   本轮信息为主信息，历史结果弱化显示，避免混淆。
    

#### 质疑操作

玩家面前显示4个选项：

*   质疑左侧玩家；
    
*   质疑顶部玩家；
    
*   质疑右侧玩家；
    
*   不质疑。
    

每人只能选择一个结果。点击选项后高亮，“确认选择”变为可用；确认后显示“已确认，等待其他玩家”，阶段结束前可取消并重选。

其他玩家只显示“选择中”或“已确认”，不展示其选择对象。倒计时结束仍未确认时，系统自动选择“不质疑”。所有玩家确认后可提前结束阶段。

### 5.4 公示阶段

公示按“被质疑玩家”逐个进行，不同时展示多人的结果。

#### 展示顺序

1.  按固定座位顺序查找本轮被质疑的玩家；
    
2.  聚焦第1名被质疑玩家，公布所有质疑者；
    
3.  翻开该玩家本轮的全部暗牌；
    
4.  展示“质疑成功”或“质疑失败”；
    
5.  展示该玩家及其质疑者的奖励、惩罚和气运变化；
    
6.  当前结果按“单个被质疑者公示时间”展示，默认10秒；
    
7.  展示结束后，再进入下一名被质疑玩家，并重新开始计时；
    
8.  没有被质疑的玩家不进入公示展示，其暗牌继续隐藏到最终结算。
    

同一玩家被多人质疑时，只进行一次翻牌和结果展示，同时列出全部质疑者，并按多人质疑规则统一结算。公示时长按被质疑玩家分别计算，不由多人共享，也不把多名被质疑玩家压缩进同一段倒计时。

#### 无人质疑

如果本轮没有任何玩家发出质疑：

*   单独显示“本轮无人发出质疑”；
    
*   所有玩家的暗牌保持隐藏；
    
*   信息停留5秒后结束公示；配图统一说明：现有公示过程图用于说明单个对象的“公布质疑者→翻牌→判定→奖惩”。正式流程存在多个被质疑玩家时，按相同过程逐个播放，不并行展示。
    

#### 判定与奖惩

*   被质疑玩家本轮出牌中有3：质疑成功；质疑者获得奖励，被质疑者受到惩罚；
    
*   被质疑玩家本轮出牌中没有3：质疑失败；质疑者受到惩罚，被质疑者获得奖励；
    
*   奖励：将1个霉运转化为好运；没有霉运则不变化；
    
*   惩罚：将1个好运转化为霉运；没有好运则不变化。
    

#### 多人质疑同一玩家

*   1人质疑：双方各正常结算1次；
    
*   2人质疑：两名质疑者分别获得奖励或惩罚，被质疑者只结算1次；
    
*   3人质疑且质疑成功：3名质疑者不获得奖励，被质疑者受到2次惩罚；
    
*   3人质疑且质疑失败：3名质疑者各受到1次惩罚，被质疑者获得2次奖励。
    

第1、2轮公示结束后进入下一轮摸牌。第3轮公示结束后直接进入气运抽取阶段。

## 6. 气运抽取阶段

### 6.1 展示

*   背景牌桌虚化并锁定操作；
    
*   中央展示自己的气运池，包括好运、霉运和总数；
    
*   抽取结果和过程仅本人可见；
    
*   显示本局允许的抽取数量范围和30秒倒计时。
    

### 6.2 操作

*   玩家通过加减按钮或数量快捷按钮选择抽取数量；
    
*   数量不能低于下限，也不能高于上限；
    
*   点击“开始抽取”后，从自己的气运池随机抽取对应数量；
    
*   已确认后不可修改；
    
*   30秒内未选择，系统按**最低抽取数量**自动抽取；
    
*   抽取结束后显示本人的好运和霉运结果，并进入等待状态；
    
*   所有玩家完成抽取后，统一进入最终结算。

## 7. 最终结算

### 7.1 结算顺序

1.  统计气运抽取结果；
    
2.  每滞留1张3，增加1个霉运；
    
3.  再结算成功溜走的3：有霉运时，每张3消除1个霉运；霉运为0时，每张3增加1个福运；
    
4.  得到“有效霉运”和“最终福运”；
    
5.  按有效霉运、最终福运、成功溜走3的数量依次排名。
    

未被质疑的暗牌在此阶段统一翻开并参与结算。

### 7.2 称号

| 有效霉运 | 最终福运 | 称号 |
| --- | --- | --- |
| 0 | 3 | 三阳开泰 |
| 0 | 4 | 四季平安 |
| 0 | 5 | 五福临门 |
| 0 | 6 | 六六大顺 |
| 0 | 7或以上 | 鸿运当头 |
| 1 | 任意 | 小有波折 |
| 2 | 任意 | 霉运缠身 |
| 3或以上 | 任意 | 诸事不顺 |

### 7.3 结算UX

*   排名表展示名次、玩家、有效霉运、最终福运、成功溜走3和称号；
    
*   当前玩家所在行标记“你”；
    
*   不展示排名升降或历史排名；
    
*   并列玩家显示相同名次；
    
*   页面底部提供“查看本局记录”“再来一局”“返回大厅”；
    
*   “再来一局”返回原房间并清空准备状态，房主参数保留。

## 8. 全局交互

### 8.1 全局按钮位置

#### 等待大厅

*   右上角：**离开房间、菜单**；
    
*   左下角：**快捷文字、文字输入**。
    

#### 对局及其他阶段

适用于摸牌、出牌、质疑、公示、气运抽取和最终结算：

*   右上角：只保留**菜单**；
    
*   左下角：固定显示**快捷文字、文字输入**；
    
*   不再显示右上角对话、表情或其他独立按钮。
    

#### 功能说明

*   快捷文字：向上展开预设语句，选择后发送；
    
*   文字输入：展开输入框和发送按钮；
    
*   菜单：规则说明、声音设置；对局中另含“返回大厅”；
    
*   返回大厅需要二次确认；
    
*   快捷文字和文字输入不能同时展开，点击空白处关闭。
    

> **最终判定原则：文字规则优先于配图；同类图片中，已替换的单张大厅大图和单张对局大图优先于旧图、三联图及流程示意图。旧图只用于说明其对应流程，不用于确定按钮位置。**

### 8.2 断线与离开

*   短暂断线后自动重连，并恢复当前阶段、剩余时间、手牌和已提交操作；
    
*   重连时若阶段已经结束，直接进入服务器当前阶段；
    
*   玩家离开或长时间未连接时，由系统托管：出牌超时打排序第一张，质疑超时不质疑，气运抽取超时取最低数量；
    
*   其他玩家只看到“托管中”，不展示断线玩家的隐藏信息。
    

### 8.3 操作反馈
